## Certificado profesional: Serie de 6 cursos

Este certificado de nivel principiante, compuesto por seis cursos y desarrollado por Google, está diseñado para proporcionar a los profesionales de TI habilidades altamente demandadas —incluyendo Python, Git y automatización de TI— que pueden ayudarte a avanzar en tu carrera.

Saber cómo escribir código para resolver problemas y automatizar soluciones es una habilidad crucial para cualquier persona en el sector de TI. Python, en particular, es actualmente el lenguaje de programación más solicitado por los empleadores.

Este programa parte de tus fundamentos de TI para ayudarte a llevar tu carrera al siguiente nivel. Está diseñado para enseñarte a programar con Python y cómo utilizarlo para automatizar tareas comunes de administración de sistemas. También aprenderás a usar Git y GitHub, a localizar y depurar problemas complejos, y a aplicar la automatización a escala mediante la gestión de configuraciones y la Nube.

Este certificado se puede completar en aproximadamente 6 meses y está diseñado para prepararte para una variedad de roles en TI, como Especialista en Soporte de TI avanzado o puestos de Administrador de Sistemas Junior. Al finalizar, puedes compartir tu información con empleadores potenciales como Deloitte, Target, Verizon y, por supuesto, Google.

Recomendamos que tengas Python instalado en tu máquina. Para algunos cursos, necesitarás una computadora donde puedas instalar Git o pedirle a tu administrador que lo instale por ti.

## Cursos

- [Curso intensivo de Python](./Automatización%20de%20TI%20con%20Python/1-Curso-intensivo-de-Python/)

Este curso está diseñado para enseñarle los fundamentos para escribir programas sencillos en Python utilizando las estructuras más comunes. No es necesaria ninguna exposición previa a la programación. Al finalizar este curso, comprenderá las ventajas de la programación en las funciones informáticas; entenderá la sintaxis básica de Python; explorará diferentes editores de código y entornos de desarrollo; será capaz de escribir programas sencillos utilizando Python; averiguará cómo encajan los componentes básicos de la programación; y combinará todos estos conocimientos para resolver un problema de programación complejo.

Comenzaremos sumergiéndonos en los fundamentos de la escritura de un programa informático. Por el camino, obtendrá experiencia práctica con conceptos de programación a través de ejercicios interactivos y ejemplos del mundo real. Rápidamente empezará a ver cómo los ordenadores pueden realizar multitud de tareas: sólo hay que escribir el código que les diga lo que tienen que hacer.

- [Uso de Python para interactuar con el Sistema operativo](./Automatización%20de%20TI%20con%20Python/2-Uso-de-Python-SO/)

Este curso está diseñado para explorar cómo ejecutar Python localmente y organizar y utilizar código en diferentes archivos Python. Los alumnos aprenderán a leer y escribir diferentes tipos de archivos, a utilizar subprocesos y flujos de entrada, a crear scripts Bash y a utilizar expresiones regulares. Este curso también cubre las pruebas automáticas y explica cómo configurar un entorno de desarrollador en una máquina personal. Comenzaremos explorando cómo ejecutar Python localmente, y organizar y utilizar código a través de diferentes archivos Python. Luego aprenderemos a leer y escribir diferentes tipos de archivos, y a utilizar subprocesos y flujos de entrada. También nos sumergiremos en las secuencias de comandos Bash y las expresiones regulares, dos herramientas muy potentes para cualquiera que trabaje con sistemas. Incluso abordaremos las pruebas automáticas, que nos permiten automatizar la forma de comprobar si nuestro código es correcto. Para terminar, juntaremos todo esto utilizando las herramientas que hemos adquirido para procesar datos y generar informes automáticos. También explicaremos cómo configurar tu propio entorno de desarrollador en tu máquina. Este es un paso clave para poder escribir y desplegar potentes herramientas de automatización.

- [Introducción a Git y GitHub](./Automatización%20de%20TI%20con%20Python/3-Git-Github/)

En este curso, aprenderá a realizar un seguimiento de las diferentes versiones de su código y archivos de configuración utilizando un popular sistema de control de versiones (VCS) llamado Git. También veremos cómo configurar una cuenta con un servicio llamado GitHub para que pueda crear sus propios repositorios remotos para almacenar su código y configuración. A lo largo de este curso, aprenderá sobre la funcionalidad básica de Git para que pueda entender cómo y por qué se utiliza en las organizaciones. Examinaremos tanto las funciones básicas como las más avanzadas, como las ramas y la fusión. Demostraremos cómo tener un conocimiento práctico de un VCS como Git puede ser un salvavidas en situaciones de emergencia o al depurar. Y luego exploraremos cómo utilizar un VCS para trabajar con otros a través de repositorios remotos, como los que proporciona GitHub. Al final de este curso, será capaz de almacenar el historial de su código en Git y colaborar con otros en GitHub, ¡donde también empezará a crear su propio portafolio! Para seguir el curso y completar las evaluaciones, necesitará un ordenador en el que pueda instalar Git o pedir a su administrador que lo instale por usted.

- [Técnicas de solución de problemas y depuración](./Automatización%20de%20TI%20con%20Python/4-Técnicas-de-solución-de-problemas-y-depuración/)

En este curso, le daremos las herramientas para identificar y resolver rápidamente los problemas del mundo real con los que podría encontrarse en su función de TI. Veremos un montón de estrategias y enfoques diferentes para abordar los escollos más comunes de su código e Infraestructura de TI. Aprenderá estrategias para abordar casi cualquier problema técnico y luego verá cómo se aplican a la resolución de distintos escenarios del mundo real. Elegimos ejemplos que incluyen problemas generales del sistema, problemas con software que escribió otra persona y problemas con programas que escribimos nosotros. Hablaremos de problemas que pueden afectar a cualquier sistema operativo, y también veremos retos específicos de ciertas plataformas y lenguajes de scripting. Le recomendamos encarecidamente que haya realizado los cursos anteriores de este programa, o que ya tenga conocimientos de Python y Linux para que pueda seguir nuestros ejemplos de resolución de problemas.

- [Gestión de la configuración y la nube](/Automatización%20de%20TI%20con%20Python/5-Gestión-de-la-configuración-y-la-nube/)

En este módulo, se le presentará el concepto de automatización a escala y cómo puede lograrse con éxito. Aprenderá lo que significa trabajar a escala y cómo se necesita la automatización para escalar con eficacia. A continuación, se le introducirá en la gestión de la configuración. Aprenderá las diferencias entre la gestión de la configuración gestionada y no gestionada. A continuación, se sumergirá en la infraestructura como código y conocerá las ventajas que aporta, como hacer que su flota de nodos sea más fiable y repetible. Este es un beneficio importante cuando se gestionan sistemas a escala. En la siguiente lección, se le presentará Puppet. Aprenderá a aplicar la gestión de configuración básica y cómo los agentes y maestros de Puppet interactúan entre sí. A continuación, hará un repaso de los recursos y clases de Puppet. Aprenderá como los recursos son unidades básicas para modelar sus configuraciones y como las clases son una colección de recursos utilizados para conseguir un único objetivo. La última lección le introducirá en los bloques de construcción del lenguaje específico del dominio. Aprenderá qué son los hechos de Puppet y cómo utiliza un programa llamado Facter para analizar, almacenar y recopilar esta información. La última lección cubrirá los principios impulsores de la gestión de la configuración. Aprenderá acerca de los principios declarativos, procedimentales e idempotentes y cómo se diferencian unos de otros.

- Comprender la definición de trabajo a escala y cómo la automatización es una herramienta esencial
- Comprender la diferencia entre sistemas de configuración gestionados y no gestionados
- Ventajas de la infraestructura como código
- Entender qué es Puppet y cómo funcionan los hechos de Puppet
- Entender qué son los recursos y las clases de Puppet
- Definir los principios de la administración de configuraciones

- [Automatización de tareas reales con Python](./Automatización%20de%20TI%20con%20Python/6-Automatización-de-tareas-reales-con-Python/)

En este curso, vamos a unir todos los conceptos que han aprendido a lo largo de este programa. Abordarán escenarios en Qwiklabs que los desafiarán a utilizar múltiples habilidades a la vez. Verán más de cerca cómo utilizar módulos externos de Python como la Python Image Library (PIL) para ampliar las capacidades de su código. También utilizarán la serialización de datos para convertir objetos en memoria en mensajes que puedan enviarse a través de programas con interfaces de programación de aplicaciones (API). Por último, los alumnos resolverán un problema del mundo real utilizando sus conocimientos técnicos para crear un programa
