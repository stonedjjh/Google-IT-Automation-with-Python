# Glosario

Convenciones de nomenclatura: Funciones, clases y métodos con convenciones de nomenclatura para entender qué esperar de ellos

Docstrings: Documentación que acompaña al código

NALSD (Non-Abstract Large System Design): Disciplina y proceso introducidos por Google, cuyo objetivo principal es capacitar a los ingenieros de fiabilidad de sitios (SRE) para evaluar, diseñar y valorar sistemas a gran escala

Sistemas distribuidos: También denominados computación distribuida o bases de datos distribuidas, utilizan diferentes nodos para interactuar y sincronizarse a través de una red compartida

Punto final de la API: La parte del programa que escucha en la red las llamadas a la API

Serialización de datos: El proceso de tomar una estructura de datos en memoria, como un objeto Python, y convertirla en algo que se pueda almacenar en disco o transmitir a través de una red

Flask: Biblioteca de Python que facilita la creación de aplicaciones web y servicios web REST

JSON: formato de intercambio de datos utilizado en las API RESTful para facilitar la comunicación entre clientes y servidores

REST (Representational State Transfer): Cada petición lleva todos los parámetros y datos necesarios para que el servidor satisfaga esa petición

API RESTful: Se basan en el protocolo HTTP, pueden protegerse aún más mediante HTTPS y los puntos finales de las API pueden autenticar a los usuarios mediante tokens de autorización, claves API u otros mecanismos de seguridad

Arquitectura REST: Estilo arquitectónico para diseñar aplicaciones y servicios web en red

Modelo de Madurez de Richardson (RMM): Marco que clasifica y describe los distintos niveles de implementación de las API RESTful en función de su cumplimiento de las seis restricciones

Aplicación web: Aplicación con la que se interactúa a través de HTTP

Presupuestos de error: Representados como la cantidad máxima de tiempo que un programa es capaz de fallar sin violar un acuerdo

Acuerdos de nivel de servicio (SLA): Acuerdo entre un proveedor y sus clientes o usuarios que puede ser legalmente vinculante

Objetivos a nivel de servicio (SLO): Un objetivo específico y medible que define el nivel de rendimiento, fiabilidad o calidad que un servicio debe ofrecer de forma constante.
